# Калькулятор электрических нагрузок (РТМ 36.18.32.4-92)

Статический веб-калькулятор для расчёта электрических нагрузок по методике
**РТМ 36.18.32.4-92** «Указания по расчету электрических нагрузок» (форма, близкая к Ф636-92).

**Сайт (GitHub Pages):** https://pafnusha.github.io/rtm-electrical-loads/

**Репозиторий:** https://github.com/Pafnusha/rtm-electrical-loads

## Возможности

- Режим **РТМ**: Ки, эффективное число ЭП nэ, коэффициент расчётной нагрузки Кр по табл. 1 или 2
- Режим **коэффициента спроса**: Рр = Кс · ΣPн
- Билинейная интерполяция Кр по табл. 1 (питающие сети ≤1000 В)
- Табл. 2 для шин НН / магистральных шинопроводов (диапазоны nэ)
- Ручной override Кр, задание Uн (по умолчанию 0,4 кВ)
- Добавление / удаление / дублирование строк ЭП
- Сохранение и загрузка JSON
- **Экспорт Excel (.xlsx) с формулами** в расчётных ячейках (ExcelJS)

## Как пользоваться

1. Откройте сайт или локально `index.html` (нужен современный браузер, ES-модули).
2. Выберите режим и таблицу Кр.
3. Заполните строки: наименование, n, Pн ед. (кВт), Ки, cos φ.
4. Смотрите итоги: ΣPн, Ки<sub>ср</sub>, nэ, Кр, Рр, Qр, Sр, Iр.
5. «Скачать Excel» — файл с листами «Исходные», «Итоги», «Справка».

> Полный текст нормативного документа на сайт не копируется. Используйте официальный РТМ.

## Формулы (кратко)

| Величина | Формула |
|----------|---------|
| Pн_i | n · Pн_ед |
| Ки·Pн_i | Ки · Pн_i |
| tgφ_i | tan(arccos(cos φ)) |
| nэ | (ΣPн)² / Σ(n · Pн_ед²) |
| Рр | Кр · Σ(Ки·Pн) |
| Qр | 1,1 · Σ(Ки·Pн) · tgφ<sub>ср</sub> при nэ ≤ 10; иначе без 1,1 |
| Sр | √(Рр² + Qр²) |
| Iр | Sр / (√3 · Uн), Uн в кВ |

При Ки ≥ 0,8 для табл. 1 принимается Кр = 1,0.

## Локальный просмотр

Из‑за ES-модулей удобнее поднять простой HTTP-сервер:

```bash
cd rtm-electrical-loads
python3 -m http.server 8080
# открыть http://localhost:8080
```
