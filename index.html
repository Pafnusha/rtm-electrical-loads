Электроприёмники (форма ведомости)

# Наименование n Pн ед., кВт Pн, кВт Ки cos φ tg φ P=Ки·Pн Q=Ки·Pн·tg n·Pн² Кс

Итого входит в Рр, Qр, Sр. КУ: Qку = Рр·Ко · (tgφ1 − tgφ2), где tgφ2 = tan(arccos(cosφ проектировщика)).

Формулы ведомости
  • Pн = n · Pн_ед;  P = Ки · Pн;  Q = Ки · Pн · tgφ
  • nэ = (ΣPн)² / Σ(n · Pн_ед²);  Рр = Кр · Σ(Ки·Pн)
  • Qр = 1,1 · Σ(Ки·Pн) · tgφср при nэ ≤ 10; иначе без 1,1
  • Итого с Ко: Рр' = Рр·Ко;  Qр' = Qр·Ко
  • Qку = Рр' · (tgφ₁ − tgφ₂);  Qпосле = Qр' − Qку
  • Sпосле = √(Рр'² + Qпосле²);  Sтр — ближайший стандартный ТМ ≥ Sпосле
