# Наименование n Pн ед., кВт Ки cos φ Кс Pн Ки·Pн tg φ

Pн строки = n · Pн_ед. tg φ = tan(arccos(cos φ)). В режиме РТМ Кр берётся из выбранной таблицы по nэ и Киср. В режиме спроса: Рр = Ксгруппы · ΣPн; Qр = Рр · tgφср.

Краткие формулы и примечания
  • nэ = (ΣPн)² / Σ(n · Pн_ед²)
  • Рр = Кр · Σ(Ки·Pн)
  • Qр = 1,1 · Σ(Ки·Pн) · tgφср при nэ ≤ 10; иначе без коэффициента 1,1
  • tgφср — средневзвешенный по Ки·Pн
  • Sр = √(Рр² + Qр²); Iр = Sр / (√3 · Uн), Uн в кВ
  • При Ки ≥ 0,8 для табл. 1 принимается Кр = 1,0
